# Contributing

Thanks for contributing.

Before opening a pull request:

1. Keep the change focused and document user-visible behavior.
2. Follow the repository's local contributor guidance and run its documented
   checks.
3. Do not commit credentials, private data, generated output, or local
   environment files.
4. Explain what changed, why it changed, and how it was validated.

Security vulnerabilities should be reported according to `SECURITY.md`, not in
a public issue.
